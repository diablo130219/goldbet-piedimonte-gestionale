# GoldBet Piedimonte — Gestionale online

Gestionale interno con due casse separate, rubrica clienti condivisa, distinte per turno, notifiche e quadratura di cassa.

**Stato:** repository sorgente, non ancora pubblicato su Internet.

Dopo il caricamento dei file, leggere [LEGGIMI-PRIMA.md](LEGGIMI-PRIMA.md) e [GUIDA-ONLINE-GITHUB.md](GUIDA-ONLINE-GITHUB.md).

Per la messa online è previsto Render con disco persistente e configurazione privata di `GB_SETUP_TOKEN`. Non inserire password o dati personali nel repository.

L'app è un registro gestionale interno e non sostituisce i sistemi autorizzati del concessionario.
